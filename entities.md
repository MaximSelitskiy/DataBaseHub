# Описание предметной области

Платформа цифровой дистрибуции и игровой аналитики представляет собой специализированную систему для распространения игр, управления пользовательскими профилями и сбора статистики игрового процесса. Системы такого рода применяются в цифровых магазинах (Steam, Epic Games Store), внутренних платформах издателей и аналитических сервисах.

Работа платформы состоит из следующих этапов:

1. В системе регистрируется пользователь (игрок, разработчик или администратор).
2. Пользователю назначается роль, определяющая уровень доступа к функциям платформы.
3. Пользователь заполняет расширенный профиль (отображаемое имя, аватар, страна, дата рождения).
4. Студия-разработчик публикует игры на платформе.
5. Игроки оставляют отзывы и оценки на игры.
6. Для каждой игры ведётся справочник достижений.
7. Игроки получают достижения в процессе прохождения игр.
8. Система фиксирует игровые сессии (время начала, длительность, устройство) для аналитики.
9. Все действия пользователей и критические системные события записываются в журнал действий.

# Абстракции предметной области

# Сущность "Роль" (Role)

| Поле         | Тип     | Ограничения             | Описание                             |
| ------------ | ------- | ----------------------- | ------------------------------------ |
| role_id      | INT     | Primary Key, Unique     | идентификатор роли                   |
| role_name    | VARCHAR | длина до 50 символов    | название роли (ADMIN, PLAYER и др.)  |
| role_description | VARCHAR | длина до 250 символов | описание полномочий роли             |

# Сущность "Пользователь" (User)

| Поле           | Тип      | Ограничения                | Описание                       |
| -------------- | -------- | -------------------------- | ------------------------------ |
| usr_id         | INT      | Primary Key, Unique        | идентификатор пользователя     |
| usr_login      | VARCHAR  | длина до 50 символов       | имя аккаунта пользователя      |
| usr_email      | VARCHAR  | длина до 100 символов      | адрес электронной почты        |
| usr_password   | VARCHAR  | длина до 255 символов      | хэш пароля пользователя        |
| usr_role_id    | INT      | Foreign Key                | роль пользователя (ссылка на Role) |
| usr_is_active  | BOOL     | default TRUE               | статус активности аккаунта     |
| usr_created_at | DATETIME | -                          | время создания аккаунта        |

# Сущность "Профиль пользователя" (UserProfile)

Описывает расширенную информацию пользователя (связь 1:1 с User)

| Поле            | Тип      | Ограничения              | Описание                                   |
| --------------- | -------- | ------------------------ | ------------------------------------------ |
| prf_usr_id      | INT      | Primary Key, Foreign Key | идентификатор пользователя (ссылка на User)|
| prf_display_name| VARCHAR  | длина до 100 символов    | отображаемое имя                           |
| prf_avatar_url  | VARCHAR  | длина до 255 символов    | ссылка на аватар                           |
| prf_country     | VARCHAR  | длина до 50 символов     | страна проживания                          |
| prf_birth_date  | DATE     | Nullable                 | дата рождения                              |
| prf_updated_at  | DATETIME | -                        | время последнего обновления профиля        |

# Сущность "Журнал действий" (ActionLog)

| Поле            | Тип      | Ограничения                | Описание                                           |
| --------------- | -------- | -------------------------- | -------------------------------------------------- |
| log_id          | INT      | Primary Key, Unique        | идентификатор записи журнала                       |
| log_usr_id      | INT      | Foreign Key                | пользователь, совершивший действие (ссылка на User)|
| log_action      | VARCHAR  | длина до 100 символов      | название выполненного действия                     |
| log_ip_address  | VARCHAR  | длина до 45 символов       | IP-адрес клиента                                   |
| log_description | VARCHAR  | длина до 500 символов      | полное описание действия                           |
| log_timestamp   | DATETIME | -                          | время создания записи                              |

# Сущность "Студия-разработчик" (DeveloperStudio)

| Поле          | Тип     | Ограничения             | Описание                          |
| ------------- | ------- | ----------------------- | --------------------------------- |
| std_id        | INT     | Primary Key, Unique     | идентификатор студии              |
| std_name      | VARCHAR | длина до 100 символов   | название студии                   |
| std_country   | VARCHAR | длина до 50 символов    | страна регистрации студии         |
| std_founded_at| DATE    | Nullable                | дата основания студии             |
| std_website   | VARCHAR | длина до 255 символов   | официальный сайт студии           |

# Сущность "Игра" (Game)

| Поле          | Тип      | Ограничения                | Описание                                   |
| ------------- | -------- | -------------------------- | ------------------------------------------ |
| game_id       | INT      | Primary Key, Unique        | идентификатор игры                         |
| game_title    | VARCHAR  | длина до 150 символов      | название игры                              |
| game_std_id   | INT      | Foreign Key                | студия-разработчик (ссылка на DeveloperStudio) |
| game_genre    | VARCHAR  | длина до 50 символов       | жанр игры                                  |
| game_price    | FLOAT    | целое положительное        | цена игры                                  |
| game_release_date | DATE | -                          | дата выхода игры                           |

# Сущность "Отзыв" (Review)

Разрешает связь M:N между User и Game, содержит текст и оценку

| Поле         | Тип      | Ограничения             | Описание                                |
| ------------ | -------- | ----------------------- | --------------------------------------- |
| rev_id       | INT      | Primary Key, Unique     | идентификатор отзыва                    |
| rev_usr_id   | INT      | Foreign Key             | автор отзыва (ссылка на User)           |
| rev_game_id  | INT      | Foreign Key             | игра, на которую оставлен отзыв (ссылка на Game) |
| rev_rating   | INT      | число от 1 до 5         | оценка игры                             |
| rev_text     | VARCHAR  | длина до 1000 символов  | текст отзыва                            |
| rev_created_at | DATETIME | -                     | время создания отзыва                   |

# Сущность "Достижение" (Achievement)

| Поле         | Тип     | Ограничения             | Описание                                |
| ------------ | ------- | ----------------------- | --------------------------------------- |
| ach_id       | INT     | Primary Key, Unique     | идентификатор достижения                |
| ach_game_id  | INT     | Foreign Key             | игра, к которой относится достижение (ссылка на Game) |
| ach_name     | VARCHAR | длина до 100 символов   | название достижения                     |
| ach_description | VARCHAR | длина до 250 символов | описание условия получения достижения   |
| ach_points   | INT     | целое положительное     | количество очков за достижение          |

# Сущность "Достижение пользователя" (UserAchievement)

Разрешает связь M:N между User и Achievement, содержит UnlockDate, поэтому является самостоятельной сущностью

| Поле         | Тип      | Ограничения             | Описание                                    |
| ------------ | -------- | ----------------------- | ------------------------------------------- |
| uach_id      | INT      | Primary Key, Unique     | идентификатор записи                        |
| uach_usr_id  | INT      | Foreign Key             | пользователь (ссылка на User)               |
| uach_ach_id  | INT      | Foreign Key             | достижение (ссылка на Achievement)          |
| uach_unlock_date | DATETIME | -                    | дата и время получения достижения           |

# Сущность "Игровая сессия" (PlaySession)

Лог игровой сессии (статистика для аналитики, связь 1:M от User и Game)

| Поле          | Тип      | Ограничения             | Описание                                    |
| ------------- | -------- | ----------------------- | ------------------------------------------- |
| ps_id         | BIGINT   | Primary Key, Unique     | идентификатор сессии                        |
| ps_usr_id     | INT      | Foreign Key             | пользователь (ссылка на User)               |
| ps_game_id    | INT      | Foreign Key             | игра (ссылка на Game)                       |
| ps_started_at | DATETIME | -                       | время начала сессии                         |
| ps_duration_sec | INT    | целое положительное     | длительность сессии в секундах              |
| ps_device     | VARCHAR  | длина до 50 символов    | устройство (PC, PS5, XBOX и др.)            |

# Сущность "Дополнение" (GameDLC)

Содержит информацию о загружаемом контенте и дополнениях к играм (Связь 1:M от Game)

| Поле               | Тип      | Ограничения             | Описание                                           |
| ------------------ | -------- | ----------------------- | -------------------------------------------------- |
| dlc_id             | INT      | Primary Key, Unique     | уникальный идентификатор дополнения                |
| dlc_game_id        | INT      | Foreign Key             | базовая игра (ссылка на Game)                      |
| dlc_title          | VARCHAR  | длина до 150 символов   | название дополнения                                |
| dlc_price          | FLOAT    | целое положительное     | цена дополнения                                    |
| dlc_release_date   | DATE     | -                       | дата выхода дополнения                             |

# Сущность "Транзакция покупки" (Purchase)

Фиксирует факт покупки игры пользователем (Связь 1:M от User и Game)

| Поле               | Тип      | Ограничения             | Описание                                           |
| ------------------ | -------- | ----------------------- | -------------------------------------------------- |
| pur_id             | BIGINT   | Primary Key, Unique     | уникальный идентификатор транзакции                |
| pur_usr_id         | INT      | Foreign Key             | покупатель (ссылка на User)                        |
| pur_game_id        | INT      | Foreign Key             | приобретаемая игра (ссылка на Game)                |
| pur_amount         | FLOAT    | целое положительное     | итоговая сумма покупки                             |
| pur_payment_method | VARCHAR  | длина до 50 символов    | способ оплаты (CARD, PAYPAL, CRYPTO и др.)         |
| pur_status         | VARCHAR  | длина до 20 символов    | статус транзакции (COMPLETED, REFUNDED и др.)      |
| pur_created_at     | DATETIME | -                       | дата и время проведения покупки                    |
